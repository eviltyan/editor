### AST конструкции  
  
### Промежуточное представление IR  
Для промежуточного представления использовались следующие виртуальные инструкции:  
CONST - создание константы (число, строка, логическое значение, NULL) и сохранение её во временную переменную.  
  
LIST - создание пустого списка для хранения аргументов функции.  
  
ADD_ARG - добавление одного аргумента в список аргументов.  
  
CALL - вызов функции (в нашем случае функции c) с переданным списком аргументов.  
  
VECTOR - прямое создание вектора указанного типа и размера (без вызова функции).  
  
SET_ELT - установка значения элемента вектора по индексу.  
  
FREE - освобождение памяти временных переменных, констант и списков после использования.  
  
Присваивание (=) - запись значения (результата вычислений) в переменную.  
  
### Оптимизации  
### Оптимизация 1: Удаление NULL  
#### Текстовое описание  
В языке R функция c() при создании вектора игнорирует значения NULL. Оптимизация удаляет все аргументы NULL из списка аргументов функции c(). Результат выполнения программы не меняется, так как NULL-значения игнорируются. Применяется в конструкциях вида  vec <- c(..., NULL, ...).  
  
#### Преимущества:  
•	Сокращение количества аргументов функции  
•	Уменьшение числа операций ADD_ARG  
•	Экономия памяти при выполнении  
•	Упрощение последующего анализа типов

### Оптимизация 2: Приведение к общему типу  
#### Текстовое описание  
Приведение аргументов к общему типу (Coercion / Canonicalization). Вектор в R может хранить элементы только одного типа. При смешении разных типов все элементы приводятся к наиболее "гибкому" типу по иерархии: NULL < logical < integer < double < character. Оптимизация выполняет это приведение и заменяет вызов c() на прямое создание вектора. Применяется в конструкциях вида vec <- c(1, TRUE, "hello") со смешанными типами.  
  
#### Преимущества:  
•	Устранение вызова функции c() во время выполнения  
•	Уменьшение числа операций (нет LIST, ADD_ARG, CALL)  
•	Все преобразования типов выполняются один раз на этапе компиляции  
•	Прямое выделение памяти под вектор нужного типа

### Оптимизация 3: Упрощение выражений  
#### Текстовое описание  
Упрощение выражений / удаление мертвого кода (Expression Simplification / Dead Code Elimination). При присваивании переменной значения NULL или при вызове c() без аргументов (вызов в итоге возвращает NULL) можно упростить IR, удалив временные переменные и операции с ними. Применяется в конструкциях вида x <- NULL и x <- c(NULL) (после оптимизации 1 превращается в c()).  
  
#### Преимущества:  
•	Удаление временных переменных t1, args  
•	Удаление операций FREE  
•	Упрощение кода до прямого присваивания x = NULL  
  
#### Блок-схема  
Оптимизация 3 в данном случае является частным случаем оптимизации 2 и показана в блок-схеме второй оптимизации. После проверки на присваивание вектору NULL-значения и проверки на вызов функции с единственным NULL-аргументом происходит прямое присваивание NULL-значения вектору.
